# 改稿意见记录

这篇文章从大纲到定稿，作者提出的意见按类别整理如下。写新文章时，这些都是要提前避开的问题。

## 内容和案例

| 作者的意见 | 对应的改法 |
|---|---|
| 之前写的案例太死板，不够贴近生活 | 换成国内一线的真实体感，比如朋友圈写真、清明 AI 复活、AI 仙侠短剧 |
| 不要虚构故事 | 所有案例改成可查证的公开报道，需要作者经历的地方先问 |
| 妙鸭那里简单带过，后面法规可以多讨论 | 产品案例压成一段，补上相关法规和落地难处 |

## 口吻和用词

| 原句 | 问题 | 改成 |
|---|---|---|
| 对我们这种刷手机的人，这是个乐子 | 把作者写成了普通刷手机的人，不专业 | 对于刷手机的人，这是个乐子 |
| 只能一遍遍刷 | 不是行业说法 | 只能一遍一遍抽卡 |
| AI 能把我画得像我，还比我好看 | 可以加一点作者式的玩笑 | 后面加上"（也有可能我原本就这么帅）" |
| 它的播放量就涨到了 166 万 | 叙事里不需要精确数字 | 它的播放量就涨到了百万 |
| 从一屏雪花点里一步步猜出画面 | 比喻不够直观 | 换成美术生画素描，起稿、铺大关系、深入刻画 |
| 质感、光影、色调在海量图片里规律很稳 | 说法抽象 | 这些东西在各种图片里的样子都差不多，AI 看得多了，很快就学会了 |
| AI 每一步只是去掉一点噪声，猜这里最可能长成什么样 | 读着奇怪 | AI 心里没有"手"这个概念，它每画一步，只是照着看过的海量图片，猜这块地方大概率长什么样 |

## 衔接

| 原句 | 问题 | 改成 |
|---|---|---|
| 故事的后半段，对做产品的人更有用。 | 突然跳出来的旁白，"像被鬼上身" | 删掉 |
| 这一段我最想记下的是那个反差。 | 同上 | 所以那段时间挺有意思。 |
| 讲 AI 视频，我想先讲一门生意。 | 不通顺 | 讲 AI 视频之前，我想先讲一门生意。 |
| 买的人不在乎做得糙不糙。（另起一段）做得确实糙。 | 两段衔接生硬 | 合成一段，补一句把"有人买"和"做得糙"连起来 |
| 上限也摆在那儿。 | 单句段，没有衔接 | 并进上一段，改成"可便宜的办法上限也低" |
| 麻烦也跟着来了。 | 和上一段接不上 | 钱进来了，争议也跟着进来。 |
| 三十秒呢？ | 问句不完整 | 那三十秒呢？ |
| 能锁住人脸，也就能拿人脸干坏事。 | 少了转折 | 但是能锁住人脸，也就能拿人脸干坏事。 |
| 画面已经像实拍了。拍什么、怎么拍，还由不得人。 | 少了转折 | 画面已经像实拍了，但是拍什么、怎么拍，还由不得人。 |
| 数字也对得上。 | 读着奇怪 | 从数字上看也对得上。 |

## 排版和配图

| 作者的意见 | 对应的改法 |
|---|---|
| 配图 4 到 5 张就够了 | 现场截图压到 4 到 5 张 |
| 示意图内容量有点多 | 每张图只讲一件事，删掉和正文重复的数字 |
| 用 Markdown 格式，把需要加图的地方标记一下就行 | 不放图片链接，每处配图用单独一行编号标记 |
| 加小标题，重要内容加粗，但不要太多 | 每章 3 到 4 个小标题，每章加粗三四处 |
| 检查一下标点 | 英文直引号统一换成中文引号，转述的指令加引号 |
