# 改稿意见记录

两篇文章从大纲到定稿，作者提出的意见按类别整理如下。写新文章时，这些都是要提前避开的问题。

# 第一篇：《被奶龙缠上以后，我把 AI 视频这几年翻了一遍》

## 内容和案例

| 作者的意见 | 对应的改法 |
|---|---|
| 之前写的案例太死板，不够贴近生活 | 换成国内一线的真实体感，比如朋友圈写真、清明 AI 复活、AI 仙侠短剧 |
| 不要虚构故事 | 所有案例改成可查证的公开报道，需要作者经历的地方先问 |
| 妙鸭那里简单带过，后面法规可以多讨论 | 产品案例压成一段，补上相关法规和落地难处 |

## 口吻和用词

| 原句 | 问题 | 改成 |
|---|---|---|
| 对我们这种刷手机的人，这是个乐子 | 把作者写成了普通刷手机的人，不专业 | 对于刷手机的人，这是个乐子 |
| 只能一遍遍刷 | 不是行业说法 | 只能一遍一遍抽卡 |
| AI 能把我画得像我，还比我好看 | 可以加一点作者式的玩笑 | 后面加上"（也有可能我原本就这么帅）" |
| 它的播放量就涨到了 166 万 | 叙事里不需要精确数字 | 它的播放量就涨到了百万 |
| 从一屏雪花点里一步步猜出画面 | 比喻不够直观 | 换成美术生画素描，起稿、铺大关系、深入刻画 |
| 质感、光影、色调在海量图片里规律很稳 | 说法抽象 | 这些东西在各种图片里的样子都差不多，AI 看得多了，很快就学会了 |
| AI 每一步只是去掉一点噪声，猜这里最可能长成什么样 | 读着奇怪 | AI 心里没有"手"这个概念，它每画一步，只是照着看过的海量图片，猜这块地方大概率长什么样 |

## 衔接

| 原句 | 问题 | 改成 |
|---|---|---|
| 故事的后半段，对做产品的人更有用。 | 突然跳出来的旁白，"像被鬼上身" | 删掉 |
| 这一段我最想记下的是那个反差。 | 同上 | 所以那段时间挺有意思。 |
| 讲 AI 视频，我想先讲一门生意。 | 不通顺 | 讲 AI 视频之前，我想先讲一门生意。 |
| 买的人不在乎做得糙不糙。（另起一段）做得确实糙。 | 两段衔接生硬 | 合成一段，补一句把"有人买"和"做得糙"连起来 |
| 上限也摆在那儿。 | 单句段，没有衔接 | 并进上一段，改成"可便宜的办法上限也低" |
| 麻烦也跟着来了。 | 和上一段接不上 | 钱进来了，争议也跟着进来。 |
| 三十秒呢？ | 问句不完整 | 那三十秒呢？ |
| 能锁住人脸，也就能拿人脸干坏事。 | 少了转折 | 但是能锁住人脸，也就能拿人脸干坏事。 |
| 画面已经像实拍了。拍什么、怎么拍，还由不得人。 | 少了转折 | 画面已经像实拍了，但是拍什么、怎么拍，还由不得人。 |
| 数字也对得上。 | 读着奇怪 | 从数字上看也对得上。 |

## 排版和配图

| 作者的意见 | 对应的改法 |
|---|---|
| 配图 4 到 5 张就够了 | 现场截图压到 4 到 5 张 |
| 示意图内容量有点多 | 每张图只讲一件事，删掉和正文重复的数字 |
| 用 Markdown 格式，把需要加图的地方标记一下就行 | 不放图片链接，每处配图用单独一行编号标记 |
| 加小标题，重要内容加粗，但不要太多 | 每章 3 到 4 个小标题，每章加粗三四处 |
| 检查一下标点 | 英文直引号统一换成中文引号，转述的指令加引号 |

## 定稿前的读者视角审稿

| 原句 | 问题 | 改成 |
|---|---|---|
| 骗了两亿人的兔子视频 | 两亿是播放次数，不是被骗的人数 | 播放超过两亿次的兔子视频 |
| 不过 AI 开口说话，也还有露馅的地方。（后面接兔子视频） | 兔子视频里没人说话，接不上 | 不过 AI 视频离挑不出毛病还远 |
| 开头 6 只，最后剩 5 只 | 和作者找到的截图对不上 | 按截图改成“8 只里的灰兔，第 4.5 秒到第 4.7 秒不见了” |
| 四　能拍剧了，可演员全是哑巴 | 标题讲哑巴，正文讲镜头控制 | 四　能拍剧了，先得让镜头听话 |
| 哑巴的事放到下一章说。 | 旁白句 | 删掉 |
| 所以那段时间挺有意思 | “所以”推不出来 | 回头看，那段时间挺有意思 |
| 两三年前辨认 AI 图的口诀（结尾） | 和引子撞词 | 当年辨认 AI 图的口诀 |
| 省下来的钱没有凭空消失 | 总结腔 | 省下来的钱，一部分…… |
| 推荐页 / 推荐栏 | 说法不统一 | 统一成推荐栏 |
| 至于奶龙，我还在想办法把它从推荐页里送走。（紧跟“提防”） | 笑点接错了对象，奶龙的问题是刷不完，跟真假无关 | 前面补一句“做一条视频便宜到这个地步，一个梗火了，几天就能长出几百条二创。” |

## 配图的第二轮调整

| 作者的意见 | 对应的改法 |
|---|---|
| 图片有点多，喧宾夺主，把文字内容用图片又展示了一遍 | 删掉时间轴、ControlNet、配音对比、成本对比四张示意图 |
| 只有一张是生成的，其他都是真实图片，会不会太割裂 | 删掉最后一张示意图，全文只留 5 张真实截图 |

| 统一图片大小，竖版对比改成横版 | 全部 1280 宽横版，兔子图拆成左右两帧并排 |
| 我要自己插入图片 | 把改好的图片按文中顺序编号，单独发过去 |

# 第二篇：《从一个单身狗的视角看情感陪伴》

## 选题和大纲

| 作者的意见 | 对应的改法 |
|---|---|
| 先确认选题和主旨，然后确立大纲，最后再写 | 每一步都等作者确认 |
| 大纲浮于表面，不希望和别人同质化，要给读者新的角度 | 每章往下挖一层机制，比如真实感从哪来、谄媚怎么训练出来、关系的成本和分量 |
| 标题和内容没什么关系（“用得越多，越孤独？”） | 换掉标题，从“关系的结束由谁决定”重新组织内容 |
| 老人陪伴写得很乱，要不要单独写 | 视角从用户变成子女，核心情绪变成愧疚，拆成单独一篇 |
| 关于情感是什么的讨论放在结尾，提供一个思考的点 | 结尾留一个开放问题，不下结论 |
| 引语出处是一本没怎么看过的网络小说 | 写成“我记得……大意是……” |
| 我没有深度体验过 | 正文只写作者给出的那段 GPT-6 练习经历 |

## 配图

| 作者的意见 | 对应的改法 |
|---|---|
| 纯文本太枯燥，要有配图，5 张以内 | 第一张作者截图，其余标出位置 |
| 除了第一张，其他的描述好让生图模型来生成 | 不生成伪造的聊天和社交媒体截图；只保留一张插画做封面，其余按作者的机制图模板写摘要 |
